# 🎀 Cream Puff Sister's Maid Coffe 🍰✨

Bem-vindo(a) ao repositório do Cream Puff Sister's Maid Coffe! Trata-se de uma landing page interativa e responsiva desenvolvida para um Maid Café/Confeitaria fictício.

O projeto foi construído com o intuito de testar meus conhecimentos mediante a frontend, combinando um design acolhedor com uma navegação imersiva e responsiva, inspirada na estética otaku/geek.

---

## 💻 Visualização
🔗 [**[Clique aqui para acessar a Landing Page](https://wendy-ps.github.io/maid-cafe-landing-page/)**]

## ✨ Funcionalidades (Features)
- 🎨 **Design Temático:** Identidade visual inspirada na cultura dos Maid Cafés.
- 📱 **100% Responsivo:** O layout se adapta a desktop e smartphones.
- 🖼️ **Galeria Interativa:** Exibição dinâmica de produtos (como bolos e macarons) e apresentação das Maids.
- ✒️ **Tipografia Cuidadosa:** Fontes escolhidas a dedo (baseadas em prototipação no Figma) para menus elegantes e legíveis.
- 🚀 **Performance:** Código otimizado sem dependências pesadas, garantindo um carregamento rápido.

## 🛠️ Tecnologias Utilizadas
* **HTML5** 
* **CSS3** (Flexbox / Grid, Variáveis de estilo, Animações)
* **JavaScript Vanilla** (Lógica de interação, máscara, animações e comportamento de interface)
* **Bootstrap 5** (Para estruturação rápida e componentes de UI)
* *Figma* (Para o estudo de layout pré-código)
